icudt78l.dat: ICU 78.1 common data, English locales only, little-endian.
Taken unmodified from Alpine Linux's icu-data-en-78.1-r0 package
(/usr/share/icu/78.1/icudt78l.dat). Firefox here is built against system
ICU, whose libicudata.so is a stub; this file is the real data, written to
/apps/firefox at launch where ICU_DATA points.

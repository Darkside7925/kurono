# Terminal App

`src/apps/terminal.cpp` and `terminal.h` implement the terminal emulator that hosts the Kurono shell.

## 1. What it is

The terminal app is a windowed VT100-compatible terminal emulator. It spawns a shell session tied to the `KuronoShell` backend and renders output in a scrollable text buffer.

## 2. Input handling

Each keystroke received by the terminal window is passed to `KuronoShell::Input()`. The shell processes the character, handles line editing and history recall, and writes output back through a character queue. The terminal reads that queue and renders new characters into the display buffer.

## 3. Display buffer

The terminal maintains a grid of character cells. Each cell has a character code, foreground color, and background color. The renderer walks the grid and draws each cell using the font engine.

Scrolling is implemented by shifting the grid up when the bottom row fills. A scroll-back buffer keeps recent history accessible via the scroll bar.

## 4. ANSI / VT100 sequences

Basic SGR sequences (colors, bold, reset) are supported. The terminal handles escape sequences generated by the shell's prompt formatting and by commands that produce colored output.

## 5. Common problems

| Problem | Likely cause |
| --- | --- |
| Text appears in wrong column | Tab stop calculation off |
| Colors wrong | SGR parameter parsing incomplete |
| Input not reaching shell | Key event not forwarded to terminal window |
| Scroll broken | Grid shift logic; check bottom-row boundary |

## 6. Related files

- `src/shell/shell.cpp` - shell backend the terminal talks to
- `src/ui/font.cpp` - character rendering
- `src/ui/gui.cpp` - window background and scroll bar
